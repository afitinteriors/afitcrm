# Desktop vs Mobile

Desktop and mobile are different products sharing the same business
logic and data layer. Expands CLAUDE.md's Product Strategy / Desktop vs
Mobile Navigation sections — CLAUDE.md wins on conflict.

- **Desktop** = management/workspace: full CRM operations.
- **Mobile** = daily operational work: the highest-frequency subset only.
- Never simply shrink the desktop UI onto a mobile viewport — build two
  intentional surfaces from one data layer.
- Automation and Audit Log remain desktop/admin-oriented; Settings is
  admin-only. None of the three appear in mobile primary nav, and none
  are visible to staff on mobile at all, unless explicitly changed.
- The mobile bottom bar stays at 4 tabs (Home/Leads/Chats/Tasks); anything
  else mobile-relevant goes in the role-aware More menu, not a 5th tab.
